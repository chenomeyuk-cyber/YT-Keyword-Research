Keyword Lab memakai YouTube Data API, saran pencarian YouTube, dan Google Trends. Semua angka adalah estimasi dari data publik. Pakai untuk membandingkan keyword di rentang waktu dan wilayah yang sama, bukan sebagai jumlah pencarian pasti.

Pengaturan

Cara dapat API key gratis
  1. Buka console.cloud.google.com, lalu buat project baru.
  2. Masuk ke APIs & Services, buka Library, cari “YouTube Data API v3”, lalu klik Enable.
  3. Masuk ke Credentials, klik Create credentials, pilih API key.
  4. Disarankan: edit key itu dan di bagian API restrictions pilih YouTube Data API v3 saja.
  5. Tempel key di kolom atas, centang “Simpan key di browser ini”, lalu klik Simpan.

Kuota gratis: 100 pencarian per hari (1 keyword = 1 pencarian), plus 10.000 unit untuk data video dan channel. Key hanya disimpan di browser ini dan hanya dikirim ke Google.

Kalau file ini dibuka langsung dari folder dan muncul galat koneksi, jalankan server lokal: buka terminal di folder file ini, ketik python -m http.server 8000, lalu buka http://localhost:8000/keyword-lab.html.
